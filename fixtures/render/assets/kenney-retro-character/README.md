# Kenney retro character render fixture

`character-medium.glb` is the committed, browser-loadable animated-mesh fixture used to prove GLB loading, named clips, skinning, cloning, playback, and disposal. It came from Kenney Animated Characters Retro 1.1 and is distributed under CC0; see `LICENSE.txt`.

- SHA-256: `c71255a41c0373f0d2ef52593369d5fd9d2f6220ae548aff8cd6bf5edb403674`
- Clips: `idle`, `run`, `jump`
- Runtime format: binary glTF (`.glb`), with no external URIs

This asset was copied from the Asha renderer donor because it is evidence for a real rendering need, not an architectural dependency on Asha.

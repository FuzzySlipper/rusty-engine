# Kenney retro character render fixture

`character-medium.glb` is the committed animated-mesh fixture for GLB loading, named clips, skinning, playback and disposal. The `asset-import`, `voxel-convert` and `csharp-engine-services` tests, the packaged SDK smoke test and the portable-asset and joint-attachment fixtures use it. It comes from Kenney Animated Characters Retro 1.1 and is distributed under CC0; see `LICENSE.txt`.

- Clips: `idle`, `run`, `jump`
- Runtime format: binary glTF (`.glb`), with no external URIs

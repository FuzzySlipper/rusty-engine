# Historical ledgers

These files record validation and limit audits from before campaign #8723
(September 2026). They are kept for provenance: which check or quota existed,
where it lived, and why a task changed it. They are not instructions.

Under campaign #8723, a mechanism these ledgers say to "retain", "preserve" or
"enforce" is not required. Keeping one still needs a concrete failure or required
behavior. See the campaign section of [AGENTS.md](../../AGENTS.md).

- [validation-inventory.md](validation-inventory.md): the #7871 raw search index
  of validation and limit sites, built by `scripts/inventory-validation.py`.
- [validation-operation-audit.md](validation-operation-audit.md): the #7872
  operation and family dispositions.
- [audit-7874.md](audit-7874.md): retained mesh publication.
- [audit-7875.md](audit-7875.md): opaque UI, input and timeline data.
- [audit-7876-conversion.md](audit-7876-conversion.md): conversion source capacity.
- [audit-7877.md](audit-7877.md): diagnostic serialization.
- [audit-7882.md](audit-7882.md): test and CI audit follow-through (#7881–7882).

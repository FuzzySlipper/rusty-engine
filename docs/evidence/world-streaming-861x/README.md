# World streaming mechanism proof

[index.json](index.json) indexes original Crew browser captures from the local
packaged SDK/runtime exercise. These establish the visible fixture and bounded
mechanism behavior before immutable pair publication; the release/review handoff
records exact-pair verification separately.

- [Swim](swim.png): accepted position stayed at Y=1, head submerged.
- [Climb](climb.png): accepted position reached the rail top at Y≈4.
- [Flight](fly.png): accepted position reached Y≈4.817. The sampled captures do
  not clearly establish flight displacement; solver/receipt evidence does.
- [NativeAOT](native-aot.png): the packaged fixture was also published and loaded
  through the NativeAOT host; after browser attachment it reported committed
  residency, mode/state proof true and submerged hover.
- Default cyan and green variant faces rendered through Engine presentation.
- The fixture reported successful copied-input background admission, state edit,
  undo/redo and save/restore, and generated-service movement checks.

Scenarios use explicit debug resets and bounded fixture requests. They do not
certify ordinary player controls or a downstream game's playability. Browser
backing resolution was 320×180 displayed at 1280×720.

[Warning capture](warning-report.json) completed for browser and Engine without
lag/dropped events. Only known screenshot-related ReadPixels performance warnings
were observed. No compatible baseline was supplied, so comparison and a clean
warning-delta claim are unavailable.
